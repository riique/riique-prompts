# riique-prompts

Coleção de prompts para agentes de IA com acesso a terminal (Claude Code, Codex, Cursor Agent e similares).

## Prompts

| Prompt | O que faz |
|---|---|
| [Auditoria completa de PC Windows](windows/analise-completa-pc-windows.md) | Analisa hardware, disco, desempenho, boot, rede, segurança, privacidade, estabilidade, backup e ambiente de dev de um PC Windows e entrega um relatório priorizado com o que corrigir. |

## Como usar

1. Abra o prompt e copie o conteúdo abaixo da linha `---`.
2. Cole no seu agente e envie. Alguns prompts pedem para abrir o agente como Administrador ou preencher um bloco de contexto.
